# Ali Ayata – GitHub Pages CV

## Yayınlama
1. Bu klasördeki dosyaları GitHub repo içine yükleyin.
2. Repo: `AyataAli/CV`
3. Settings → Pages → Deploy from branch → `main` / root
4. Yayın adresi:
   https://AyataAli.github.io/CV

## Dosyalar
- `index.html`: Detaylı web CV
- `Lebenslauf_Ali_Ayata_final_sade_imza.pdf`: PDF CV

## Düzenleme
- GitHub üzerinde `index.html` dosyasını açıp kalem simgesi ile düzenleyebilirsiniz.
- Web sayfasında görünen “HTML herunterladen” düğmesiyle düzenlenmiş kopyayı indirebilirsiniz.
